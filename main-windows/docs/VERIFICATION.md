# Проверка ProcureFlow Windows 1.1

Дата: 23 сентября 2026. Node.js 24.14.0, Electron 44.4.5, Windows x64.

- 72 автоматические проверки: 14 расчёта, 11 проектов, 11 безопасности desktop, 24 критериев ТЗ, 12 локализации — пройдены.
- `check:offline` — пройден; npm audit сообщил 0 известных уязвимостей.
- 58 динамических проверок в работающем приложении — пройдены, ошибок консоли нет.
- Из них 36 проверяют локализацию: пять экранов RU/KK/EN, сохранение выбора, неизменность данных/количеств/утверждений, незавершённые формы, стабильные ключи складов/валюты/1С, перевод обоснований.
- Сканирование английских экранов и основных диалогов не обнаружило непереведённых строк интерфейса; данные пользователя проверяются отдельно и не переводятся.
- Визуально проверены английский и казахский экраны.
- Native menu, Save/Open и подтверждение закрытия поддерживают три языка; IPC принимает только ru/kk/en от главного доверенного окна.

Протоколы: [запуск из исходников](verification/language-smoke.json), [упакованный EXE](verification/packaged-smoke.json). В упакованном EXE все 58 проверок также прошли.
Проверки используются и при сборке в GitHub Actions. Реальные коммерческие архивы в репозиторий не включены. Код расчёта и импортера при локализации не менялся.
Установка/удаление Setup, обмен с рабочей базой 1С и выполнение workflows в аккаунте GitHub пользователя не проверялись.
