# Сервис автоматического формирования заказов поставщикам | ТОО «Электрокомплект» (ekt.kz)

Решение разработано в рамках хакатона HACKALEM AI для автоматизации закупочной деятельности ТОО «Электрокомплект».

---

## 📌 1. Обзор проекта и проблема

### Проблема
Ранее менеджеры отдела закупа рассчитывали потребность в пополнении складов вручную с помощью Excel. Из-за высокого объёма номенклатуры расчёты проводились нерегулярно и без учёта многих факторов (товары в пути, упущенные продажи в дни дефицита, разовые крупнооптовые заказы). Это приводило к:
* Затовариванию склада и избыточным издержкам на хранение.
* Дефициту (stockout) и упущенной выручке по ходовым позициям.
* Искажению регулярной потребности из-за единичных крупных сделок.

### Ценность решения
* Сокращение расходов: Снижение издержек на хранение избыточных запасов (особенно категории C).
* Предотвращение дефицита: Автоматический учёт упущенного спроса и товаров в пути (категории A / AX, AY).
* Прозрачность и управляемость: Использование классического ABC/XYZ-анализа и понятной интерпретации (explainability) по каждому предложенному заказу.
* Безопасность: Полный контроль человека (*Human-in-the-loop*) — отправка заказов осуществляется только после утверждения менеджером.

## 📊 2. ABC/XYZ Классификация номенклатуры

Для эффективной работы алгоритма пополнения запасов вся номенклатура автоматически распределяется по матрице ABC/XYZ:

### 2.1. ABC-анализ (Вклад в выручку / прибыль)
* A (Высокая ценность): Топ 20% артикулов, обеспечивающие ~80% совокупного оборота/выручки. Требуют минимального страхового запаса, но строгого контроля отсутствия дефицита.
* B (Средняя ценность): Следующие 30% артикулов, обеспечивающие ~15% оборота.
* C (Низкая ценность): Остальные 50% артикулов, обеспечивающие ~5% оборота. Требуют оптимизации объёма партии (EOQ) и оптимизации хранения.

### 2.2. XYZ-анализ (Стабильность и прогнозируемость спроса)
Рассчитывается на основе коэффициента вариации ($v$ или $CV$):
$$CV = \frac{\sigma}{\bar{x}}$$
где $\sigma$ — стандартное отклонение недельных/месячных продаж, $\bar{x}$ — средние продажи.

* X ($CV \le 10\%-20\%$): Высокая стабильность спроса, устойчивые тренды. Прогнозирование с высокой точностью (статистические модели, экспоненциальное сглаживание).
* Y ($20\% < CV \le 50\%$): Колеблющийся спрос, присутствие выраженной сезонности или тренда. Применяются модели прогнозирования с учетом сезонных индексов.
* Z ($CV > 50\%$): Спорадический (нерегулярный) спрос, случайные продажи. Прогнозирование классическими временными рядами затруднено; используются вероятностные методы (модель Кроэстона, буферные страховые запасы).

### 2.3. Матрица стратегий управления запасами (Таблица сегментов)

| Сегмент | Характеристика | Стратегия закупа / Модель прогноза |
| :--- | :--- | :--- |
| AX / AY | Высокая выручка, прогнозируемый / сезонный спрос | Приоритет №1. Автоматический прогноз (ARIMA/Prophet/XGBoost). Минимальный риск stockout, страховой запас средний. |
| AZ | Высокая выручка, нерегулярные крупные продажи | Анализ разовых крупных сделок. Страховой запас на базе вероятностей. Требует внимания менеджера. |
| BX / BY | Средняя выручка, стабильный / сезонный спрос | Регулярный автозаказ по точке перезаказа (Reorder Point). |
| BZ | Средняя выручка, нестабильный спрос | Заказ по достижении минимального порогового остатка. |
| CX / CY | Низкая выручка, стабильный спрос | Автоматический закуп крупными партиями (оптимизация логистики). |
| CZ | Низкая выручка, спорадический спрос | Зона риска затоваривания. Заказ строго под клиентский резерв или с увеличенным интервалом проверки. |
