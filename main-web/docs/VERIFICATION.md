# Проверка ProcureFlow Web 1.1

Дата: 23 сентября 2026. Node.js 24.14.0, Windows x64.

- 72 автоматические проверки: 14 расчёта, 11 проектов, 24 критериев ТЗ, 11 HTTP/упаковки, 12 локализации — пройдены.
- `check:offline` — пройден; ресурсы и словари поставляются локально, сетевые API интерфейса отсутствуют.
- `npm run build` — создаёт `_site/` из 14 публичных файлов, включая оба языковых модуля.
- Проверены корень сайта и URL с подпапкой GitHub Pages, защита путей, GET/HEAD, запрет POST и выдачи приватных файлов.
- Языки ru/kk/en сохраняются в localStorage отдельно от `.pfproject`. Проверены словари, плейсхолдеры, отсутствие изменения пользовательских значений и расчёта.
- Общий интерфейс проверен в Electron: пять экранов на трёх языках, открытые формы, поля 1С, складские ключи, утверждения и импорт/экспорт.

Внешний браузерный инструмент в этой среде недоступен; отдельный повторный UI-тест в Chrome/Edge не выполнялся. HTTP, общие модули интерфейса и языковой механизм проверены описанными способами.
Публикация GitHub Pages не выполнялась: workflow подготовлен для загрузки пользователем.
