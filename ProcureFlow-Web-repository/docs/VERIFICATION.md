# Проверка выделенной веб-версии

Дата: 23 сентября 2026. Node.js 24.14.0, Windows x64.

- `npm ci --ignore-scripts --no-audit --no-fund` — успешно, внешних зависимостей нет.
- `npm test` — 60 успешных проверок: 14 расчётных, 11 формата проекта, 24 приёмочных по ТЗ, 11 упаковки и HTTP.
- `npm run check:offline` — все ресурсы интерфейса локальные, сетевые API отсутствуют, CSP запрещает подключения.
- `npm run build` — успешно, `_site/` содержит ровно 12 публичных файлов.
- Проверены `/` и `/procureflow-web/`, относительные ссылки HTML и worker, редирект с URL без завершающего `/`, запрет чтения конфигурации/данных, обходов пути, POST и чужого Host.
- Модуль обезличивания и код worker дополнительно выполнены в изолированном JS-контексте Node. Это не браузерный UI-тест.

Браузерный инструмент не запустился из-за ошибки системной песочницы. Повторная интерактивная проверка веб-интерфейса в этом разделении не выполнялась. Расчётное ядро, импорт и формат проекта перенесены из ранее проверенной версии 1.0.
Публикация в аккаунт GitHub не выполнялась; действия workflow и адрес сайта можно проверить после загрузки репозитория и включения Pages.

Веб- и Windows-версии используют одинаковые engine.js, planner.js, project.js, xlsx.js и app.js. На вебе дополнительно уточнены CSP, подпись версии и сообщение о необходимости HTTPS/localhost.
