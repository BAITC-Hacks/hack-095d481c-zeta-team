# Проверки версии 0.2.0

Дата проверки: 23 сентября 2026 года.

## Что действительно выполнено

На Linux, Node.js 22: `npm test` — **36 успешных тестов** (14 расчётных, 11 файлов проектов, 11 статических проверок ограничений и конфигурации desktop). Все JavaScript-файлы прошли `node --check`. `npm run check:offline` подтверждает локальные зависимости интерфейса и отсутствие сетевых API в его коде. Проверена структура YAML и совпадение основной и видимой резервной копий workflow. Расчётное ядро `assets/engine.js` побайтно совпадает с исходным репозиторием.

На Chromium/Linux выполнены **15 интеграционных проверок интерфейса**, включая загрузку всех шести предоставленных XLSX, сохранение проекта, восстановление идентичных количеств заказа и экспорт XLSX с повторным открытием. Подробности: `verification/browser-report.json`. Файлы с коммерческими данными не включены в репозиторий.

**Особенность среды проверки:** администратор среды блокирует переходы к локальным URL и file://. Поэтому DOM приложения, исходные CSS и JavaScript были загружены инструментом тестирования в about:blank; сеть была отключена. Это проверяет интерфейс, парсер и расчёты, но не подтверждает запуск страницы по её настоящему URL. Политики среды не изменялись.

## Что здесь не проверено

- Windows-приложение ещё не скомпилировано: в этой среде недоступна загрузка зависимостей сборки. В архиве нет готового EXE.
- Не выполнен запуск Electron, обработчика procureflow://, native IPC и системных диалогов Windows.
- Не выполнен workflow в GitHub Actions и не проверены установка/переносной запуск на компьютере менеджера.
- Статические проверки безопасности не заменяют аудит.

## Что проверяет предусмотренная Windows-сборка

После запуска workflow `Build Windows EXE` на GitHub он устанавливает инструменты, повторяет тесты, создаёт Portable и Setup, затем запускает собранное приложение с `--smoke-test`. Результат проверки native-приложения записывается в `desktop-smoke.json`. Успешный статус этих проверок возможен только после реального запуска workflow, а не после скачивания данного архива.

Перед демонстрацией отдельно проверьте на целевом Windows-компьютере запуск при отключённом интернете, загрузку Excel, сохранение/открытие проекта, экспорт и закрытие приложения с несохранёнными изменениями. Ни одна автоматическая проверка не подтверждает экономическую точность модели без бизнес-валидации.
